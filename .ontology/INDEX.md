# magento2-extension

**Language**: PHP (Magento 2)
**Purpose**: Official public Ometria extension for Magento 2. Adds Ometria tracking (abandoned carts, orders, contacts) to Magento 2 storefronts. Distributed via Composer.

## Key capabilities
- Magento 2 modules: `Ometria_AbandonedCarts`, `Ometria_Api`, `Ometria_Core`
- Installed via Composer: `composer require ometria/magento2`
- Tracks orders, contacts, basket abandonment events

## Code structure
- `app/` — Magento 2 module code

## Related repos
